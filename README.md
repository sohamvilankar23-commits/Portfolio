# Soham Vilankar — Personal Developer Portfolio

> **"I build intelligent software that solves real problems."**

A modern, high-contrast developer portfolio designed with a bright cyan and light aesthetic, smooth animations, and responsive architecture. Built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript**, optimized for fast loading and zero-dependency deployment via **GitHub Pages**.

---

## 🎨 Design Direction: Cyan & Light Palette

Unlike traditional dark-mode developer sites, this portfolio embraces a bright, clean, and elegant light theme with vibrant cyan, deep teal, and subtle violet accents:

| Token | Hex Value | Role |
| :--- | :--- | :--- |
| **Primary Cyan** | `#06B6D4` | Primary brand accent, glowing rings, badges, active states |
| **Deep Teal** | `#0F766E` | Secondary brand anchor, high-contrast headings, icons |
| **Page Background** | `#F8FAFC` | Crisp, modern slate-50 light background |
| **Card Surface** | `#FFFFFF` | Elevated white cards with subtle multi-layer shadows |
| **Primary Text** | `#172554` | Deep navy for optimal readability & WCAG contrast |
| **Secondary Text** | `#64748B` | Refined slate for descriptions and metadata |
| **Soft Cyan** | `#CFFAFE` | Pill backgrounds, tags, and subtle hover tints |
| **Violet Accent** | `#8B5CF6` | AI and machine learning accent highlights |

### Key Aesthetic Features
- **Modern Typography**: Google Fonts (`Plus Jakarta Sans` for clean UI, `JetBrains Mono` for tech chips and code metrics).
- **Subtle Glassmorphism**: Translucent sticky navbar with backdrop blur and active section indicator pill.
- **Ambient Glow Orbs**: Gentle radial gradient orbs creating depth without clutter.
- **Scroll Reveal Animations**: Smooth entry transitions powered by a lightweight `IntersectionObserver`.
- **Zero Heavy Dependencies**: 100% pure HTML, CSS, and Vanilla JS.

## 💻 Local Testing

You can preview the website locally using any of the following simple methods:

### Option 1: Direct Browser Open
Double-click `index.html` in your file explorer or open it directly in Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Using Python Simple HTTP Server
Open your terminal inside the repository folder and run:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

### Option 3: Using VS Code Live Server
Right-click `index.html` in VS Code and select **"Open with Live Server"**.

## 🛠️ Step-by-Step GitHub Update & Deployment

To push these updates to your existing GitHub repository and deploy via GitHub Pages:

### Step 1: Open Terminal in Your Local Repository
```bash
cd "D:\projects for github\portfolio-repo"
```

### Step 2: Check Status of Changed Files
```bash
git status
```
You will see `index.html`, `styles.css`, `script.js`, and `README.md` marked as modified.

### Step 3: Stage and Commit the Changes
```bash
git add index.html styles.css script.js README.md
git commit -m "feat: complete redesign with cyan light theme, flagship project cards, and responsive layout"
```

### Step 4: Push to Your Existing GitHub Repository
```bash
git push origin main
```

### Step 5: Enable or Verify GitHub Pages
1. Navigate to your repository on GitHub:  
   [https://github.com/sohamvilankar23-commits/Portfolio](https://github.com/sohamvilankar23-commits/Portfolio)
2. Click **Settings** (top navigation tab).
3. In the left sidebar, click **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` and folder `/ (root)`.
   - Click **Save**.
5. Wait 1–2 minutes for GitHub to build the site. Your live website will be published at:  
   **`https://sohamvilankar23-commits.github.io/Portfolio/`**
